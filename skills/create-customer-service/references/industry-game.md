# 行业参考：游戏与泛娱乐（含电竞/手游）

适用于游戏、电竞、泛娱乐类商户。追问时只关注以下缺口，不生成商户未确认的内容。

## 常见业务对象
- 游戏内货币／点券／钻石等充值体系、礼包、通行证、皮肤／角色／道具
- 账号体系（游客登录、渠道服、官服互通）、实名认证与防沉迷
- 赛事、活动、赛季周期

## 追问清单
1. **充值与退款**：充值渠道（官方／iOS／安卓渠道服）；退款政策与时效；退款后道具回收规则；代充是否官方认可。
2. **账号问题**：找回账号需要什么信息；封号申诉流程与时长；实名认证与未成年限制；换绑手机／邮箱流程。
3. **道具与账务**：到账延迟的处理；补发规则；活动奖励漏发怎么办。
4. **对局与竞技**：挂机／演员举报；段位／匹配问题是否在客服范围；外挂举报渠道。
5. **服务边界**：是否支持代练、代充、账号交易类咨询（通常明确禁止）；转人工渠道与时段。

## 高风险边界
- 不承诺具体退款结果与时效（退款由渠道方审核）。
- 不参与账号交易、代练、外挂等违规话题；直接礼貌拒绝并说明规则。
- 涉及未成年人充值退款的，按商户政策处理，无法确认时转人工。
